## [0.9.0](https://github.com/hwittenborn/alto/releases/tag/v0.9.0) (2026-10-28)

First release of Alto, the successor to Celeste.

### Added
- Two-way sync between folders on this computer and Google Drive, Dropbox, Proton Drive, Nextcloud, ownCloud and WebDAV, powered by rclone's remote control API.
- Changes on this computer are synced right away, and the server is checked regularly.
- Safe syncing from several computers at once: every change is compared against the last synced state of each side, and files changed on both sides are never overwritten.
- Conflict resolution that keeps the local version, the remote version or both.
- Shared exclusion lists in `.altoignore` files using `.gitignore` syntax.
- Confirmation before propagating mass deletions, and deleted local files go to the trash.
- Live progress, when each folder was last checked, sync status in the panel, and notifications for conflicts.
- Pausing and resuming a folder, and creating the server folder to sync into.
- A sidebar that narrows to the accounts' avatars.
- rclone is set up on the first start, so there's nothing else to install.
- Running in the background at login.
